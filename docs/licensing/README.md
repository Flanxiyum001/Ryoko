# Ryoko licensing

> **Status: proposal only — not an adopted license change.**

This directory documents a proposed licensing strategy for Ryoko's future community and commercial offerings. It does not change the license of any existing release or contribution.

## Current effective terms

The repository's published source remains licensed under the Apache License, Version 2.0. The root [LICENSE](../../LICENSE), existing release artifacts, and permissions already granted to recipients remain governed by their applicable Apache-2.0 terms.

## Proposed direction

For a future, explicitly announced community release, the maintainer is considering **GNU Affero General Public License v3.0 (AGPL-3.0-only)**, alongside a separately negotiated commercial license for customers who need different terms. This would support a community edition plus official hosted and enterprise services.

The proposal is not an automatic change. The maintainer must approve the transition, choose an effective release boundary, complete the rights and dependency review, and publish the actual license text and notices in a separate implementation change.
