      Settings
      
      
      
    

    

      

        
Provider catalog

        
A validated ryoko.providers-style catalog. API keys stay in environment variables referenced by api_key_env.

        
        
      

      

        
Language servers

        
Each language gets one owner server (columns: id, command, languages, args). ryoko-lsp always runs beside them.

        

        

          
          
        

      

      

        
Color theme

        
Changes the workbench and the editor together. Also available from View › Color Theme.

        
        
      

      

        
Editor mode

        
Vim and Emacs modes apply to the Monaco editor. Workbench chords such as Mod+S still save; single-modifier editor motions stay with the editor.

        
        
      

      

        
Import from VS Code

        
Import a VS Code color-theme JSON or settings.json. Values are validated locally; nothing is uploaded. Theme colors are mapped onto Ryoko's Monaco theme and workbench variables.

        

          
          
          
          
        

        

      

      

        
Updates

        
Ryoko tells you when a new version is published and installs it only when you choose to. Each update is checked against Ryoko's signing key before it is installed.

        

      

      

        
Keybindings

        
Chords like Mod+Shift+F (Mod = Cmd on macOS, Ctrl elsewhere), stored per machine.
