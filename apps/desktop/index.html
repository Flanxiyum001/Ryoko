Getting started

  1. Register Ryoko as a GitHub App with selected repositories.
  2. Configure App ID, client ID, client secret, webhook secret and server-side private key.
  3. Sign in and choose an installation.
  4. Inspect repositories, agent worktrees and pending approvals here.

See docs/GITHUB_APP.md for exact permissions and deployment requirements.
